# 资金账户

## 资金账户管理

- 接口基础路径：`POST /erp/v1/masterData/fundAccount/*`
- 能力：列表、动态表单、草稿、正式保存和启用状态维护。

## 业务选择

- 业务编码：`FUND_ACCOUNT`。
- 用途：收款单、预收款等业务单据选择可用资金账户。
- 快捷搜索：`docs/api/endpoints/master-data-fund-account-business-select-quick-search.md`
- 弹窗搜索：`docs/api/endpoints/master-data-fund-account-business-select-dialog-search.md`
- 按 ID 回显：`docs/api/endpoints/master-data-fund-account-business-select-get-by-id.md`
