# 前后端契约规范

## 事实源

- 单接口完整事实维护在 `docs/api/endpoints/<domain>-<action>.md`。
- 业务聚合维护在 `docs/kn/*-m.md`，功能聚合维护在 `docs/kn/*-s.md`，导航维护在 `docs/kn/总目录.md`。
- 接口新增或 URL、请求方式、DTO、VO、响应规则变化时，必须执行 `.claude/commands/multi-player/SKILL.md`。

## 变更控制

- 在实现前确认调用方、兼容策略、字段默认值、空值语义和错误码；破坏性变更必须提供版本或迁移方案。
- 列表字段、筛选器、按钮、行操作从公共元数据接口下发；新建/编辑页从 `headList + data` 渲染，前端不得复制后端字段规则。
- 联调前以 API 原子文档核对请求示例、响应示例和异常场景；交付报告记录前端仓库对应分支或待联调项。
