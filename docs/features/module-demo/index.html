ERP 字段设计器

粘贴建表 SQL，确认字段页面属性，生成可直接交给业务模块交付 Skill 的字段设计 YAML。

纯离线运行 · 无外部依赖

主副表均过滤：id、corpid、del、add_time、update_time

字段配置 0

关闭“启用”的字段不会写入 YAML；不可筛选类型切换后会自动关闭“可筛选”。

表单分组

开启后通过字段卡片的“所属分组”快速迁移字段；关闭时保留设置，但 YAML 和文档不输出分组。

请先粘贴 SQL 并点击“解析字段”，或手动新增字段。

列表动作

快捷选项会写入 YAML；选择“自定义”可填写稳定动作编码和显示名称。

默认展示“新建”和“删除”；可继续新增、删除或调整每个头部按钮。

菜单路由

选择菜单所属领域；选择“自定义”后可填写任意领域 alias。

模块指导文档

按“业务域、SQL、YAML、菜单”结构生成 Markdown 文档。

点击“选择目录并保存”后选择实际输出目录；不支持目录选择的浏览器会下载文档。
