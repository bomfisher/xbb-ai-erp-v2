## 结构化输入示例

- 输入：`subjectLabel=客户，scope=save,draft，docMode=both，requirements=优先增量更新`
- 期望行为：先定位或更新 `docs/kn/customer-m.md` 的保存类章节，再同步 `docs/kn/save-s.md` 与 `docs/kn/draft-s.md` 中的客户条目

## 自然语言输入示例

- 输入：`帮我补客户保存和草稿相关的业务文档与功能文档，已有文档尽量不要重写`
- 期望行为：抽取业务主题、功能范围与更新偏好；缺字段时反问；有 API 原子文档时优先引用其路径

## 冲突示例

- 输入：只给“采购保存”，但仓库中出现多个可能业务文档或多个功能文档候选
- 期望行为：输出候选与来源，暂停并询问用户
