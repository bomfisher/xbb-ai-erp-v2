## 事实来源优先级

1. 用户显式输入
2. 当前仓库现有业务聚合文档
3. 当前仓库现有功能聚合文档
4. `docs/api/endpoints` 下的 API 原子文档
5. `docs/superpowers/specs` 与 plans
6. 当前仓库代码事实

## 更新模式

- 业务聚合文档不存在：新建
- 业务聚合文档存在且结构匹配：增量更新
- 业务聚合文档存在但结构不匹配：暂停并询问是否重写
- 功能聚合文档默认增量更新，不主动整体重写

## 冲突处理

- 业务聚合文档与功能聚合文档冲突：以业务聚合文档为准
- 聚合文档与 API 原子文档冲突：列出候选与来源，停止拍板
- 候选业务聚合文档或功能聚合文档不唯一：暂停并反问

## 待确认输出格式

- `待确认：事项；候选：A / B；来源：...`

## 文档边界硬约束

- API 原子文档是单接口完整事实源
- 业务聚合文档不得复制 API 原子文档的完整请求示例、响应示例和字段说明
- 功能聚合文档不得复制 API 原子文档的完整请求示例、响应示例和字段说明
- `docMode=both` 时必须先更新业务聚合文档，再更新功能聚合文档

## 目录与命名硬约束

- 业务聚合文档输出目录：`docs/kn`
- 功能聚合文档输出目录：`docs/kn`
- 业务聚合文档文件名使用 `-m`
- 功能聚合文档文件名使用 `-s`
