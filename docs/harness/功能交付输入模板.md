# 功能交付输入模板

每个非微小功能在开发前至少补齐以下内容。信息不完整时，先列出待确认项，不以猜测替代业务规则。

```md
## 功能
- 主题：
- 目标用户与业务价值：
- 涉及模块：

## 领域边界
- 聚合根与子实体：
- 不包含的能力：
- 外部依赖与权限：

## 页面与接口
- 列表：筛选、字段、按钮、行操作：
- 新建/编辑：字段场景、默认值、分区状态：
- 保存/草稿：校验、事务、删除语义：

## 数据变化
- 新增或变更表/字段/索引：
- Flyway 迁移编号：
- 历史数据兼容策略：

## 验收标准
- 成功场景：
- 失败与边界场景：
- 需要的单元、集成、接口契约或前端联调验证：
```

功能规格、代码生成 YAML、API 原子文档与测试名称应使用相同的业务主题，形成可追溯链路。
