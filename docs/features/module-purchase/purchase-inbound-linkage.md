# 采购入库新建页联动

## 目标

采购入库新建页支持按供应商筛选待入库采购订单、从订单回填供应商和待入库产品、实时汇总金额，以及表头仓库变更时按用户确认同步分录仓库。

## 契约分层

- `headList`：`main.purchaseOrderId` 使用 `PURCHASE_ORDER` 选择器，并显式下发 `selectionFillConfig.enabled=true`；子表下发分录仓库与金额只读字段。
- 选择器：采购订单候选接口固定过滤当前租户的待入库订单；`supplierId` 有值时附加供应商条件，无值时只执行待入库条件。
- 回填接口：采购入库模块的 `selectionFill` 校验订单和租户，返回供应商与待入库订单行的表单 `patch`。
- 表单联动元数据：后端 `SaveItemVO.linkageConfig` 下发选择查询上下文、清空 patch、行金额/总额公式和仓库同步确认规则；通用动态表单容器负责请求、应用 patch、计算和弹窗，业务新建页不维护字段监听。
- 正式保存：服务端重新校验订单、供应商、订单行、待入库数量、SKU 和采购单价，并重新计算金额，前端计算结果不作为事实源。

## 交互规则

1. 已选供应商时，采购订单搜索仅展示该供应商的待入库订单；未选供应商时展示所有待入库订单。
2. 选择订单后，回填订单供应商和所有尚有待入库数量的产品行；各行数量默认剩余数量。
3. 任意分录数量或采购单价变化后，更新行 `amount`，并汇总写入表头 `main.totalAmount`。
4. 表头仓库变化且已有分录时，用户确认后才覆盖全部 `items[].warehouseId`；取消仅保留分录仓库，表头仍变更。
5. 在已有表头仓库后再回填订单时，缺失的分录仓库自动继承表头默认仓库，不覆盖用户已调整的分录仓库；包含 `PRODUCT(50)` 的子表为空时由公共组件展示一条空分录，提交时自动过滤空行。

## 数据变更

`V11__add_purchase_inbound_item_warehouse.sql` 为 `purchase_inbound_item` 新增可索引的 `warehouse_id`。库存确认按分录仓库记账，而不再强制使用表头仓库。
